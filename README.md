# Kenned Code Disparos

Snapshot: **v2.3.2-r5**. Versão recomendada: **2.3.2 R9**, sem vendas e financeiro.

Código e histórico dos aplicativos para Windows. Integração WhatsApp Baileys não oficial.

## Downloads

Os instaladores estão em [Releases](https://github.com/KennedG/kenned-code-disparos/releases). A versão de maior número nem sempre é a recomendada: versões antigas são preservadas como histórico. Não há atualização automática entre linhas diferentes.

## Origem e preservação

Esta importação preserva instaladores originais e registra SHA-256 por versão. Onde não havia ZIP de fontes, foram recuperados os arquivos do pacote instalado; scripts de desenvolvimento ausentes não foram inventados. Exemplos pessoais encontrados em testes foram anonimizados na cópia pública. Não estão incluídos bancos de usuários, sessões WhatsApp, credenciais ou chaves administrativas de licenciamento.

As pastas privadas do Google Drive permanecem preservadas; publicar aqui não torna o Drive público nem configura sincronização automática.

## Validação

Os resultados históricos de testes não significam validação atual com WhatsApp real. Na R9, 1.423 testes automatizados passaram, além do teste da interface empacotada com conexão controlada. O recebimento de comandos na R8 foi relatado pelo usuário. Não se presume que todas as versões antigas estejam aptas para produção.
