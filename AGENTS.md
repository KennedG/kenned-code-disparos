Este projeto usa exclusivamente a base verificada 2.3.2 (linha originalmente baseada na 2.3.0) do Kenned Code Disparos. Preserve campanhas, BUSCAS, modelos, contatos, lembretes e controles operacionais. Não adicione módulos de vendas, estoque comercial, caixa, financeiro, custos, margens ou relatórios financeiros. Não implemente comparação automática de ofertas equivalentes. A integração Baileys é não oficial. Testes simulados e sockets controlados não comprovam recebimento real pelo WhatsApp. Mantenha explícitas as validações que exigem uma conta conectada e o número particular autorizado do dono.
