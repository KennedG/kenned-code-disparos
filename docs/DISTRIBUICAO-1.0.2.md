# Distribuição da versão 1.0.2

Esta atualização preserva as funcionalidades e correções da versão 1.0.1. O pacote Windows inclui os idiomas português do Brasil e inglês do runtime Electron e usa compressão máxima. Outros pacotes de idioma do Chromium foram removidos para reduzir o download; bibliotecas e funcionalidades do aplicativo foram preservadas.

A instalação continua sendo feita por um único arquivo `.exe`, com o runtime incluído. O usuário não precisa instalar Node.js ou usar terminal.

Os testes de programação de campanhas, autorização, pausa, persistência e proteção contra duplicidade são os mesmos da revisão 1.0.1. O pacote será verificado quanto à integridade e correspondência com o código-fonte antes da entrega. A instalação em Windows físico e os envios reais pelo WhatsApp continuam sem validação neste ambiente.
